# LightStage maintenance

Preserve the approved material study in `reference/` when changing visual treatments. Keep reusable surfaces in `src/`; showcase geometry and copy belong in `example/`.

For integration or API changes, read `docs/FOR-AGENTS.md`. For release work, read `docs/RELEASE.md`. Record checks actually performed in `docs/VERIFICATION.md`.

The public thakoreh/lightstage repository and MIT license are owner-approved. Keep `private: true` as the guard against unapproved npm publication. Hosted deployment, npm publication and social posting remain separate decisions. Preserve generated dist/ for GitHub archive installs; CI checks that it matches the canonical source.
